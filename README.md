# Diabetes-Prediction
📌 Project Overview

Diabetes is a chronic health condition that requires early detection to reduce long-term complications. This project uses a Support Vector Machine (SVM) model to predict whether an individual is likely to have diabetes based on medical and demographic data.

🎯 Objective

The goal of this project is to build an accurate classification model using SVM that can identify diabetic and non-diabetic individuals by analyzing key health indicators.

📊 Dataset

The dataset includes the following features:
1. Glucose level
2. Blood pressure
3. Insulin level
4. Body Mass Index (BMI)
5. Age
6. Outcome (Diabetic / Non-Diabetic)

The dataset is cleaned and preprocessed to handle missing values and ensure optimal model performance.

🛠️ Technologies Used
-> Python
-> NumPy
-> Pandas
-> Matplotlib / Seaborn
-> Scikit-learn

🤖 Machine Learning Model

Support Vector Machine (SVM)
SVM is used for classification by finding an optimal hyperplane that separates diabetic and non-diabetic data points effectively.

🔍 Workflow
-> Data loading and exploration
-> Data preprocessing and normalization
-> Train-test data splitting
-> Model training using SVM
-> Model evaluation
-> Prediction on new data

✅ Results

The SVM model provides reliable predictions and performs well in classifying individuals based on health parameters.
